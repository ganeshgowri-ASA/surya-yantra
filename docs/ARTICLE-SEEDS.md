## Seed A: GUM-Compliant IEC 60891 Corrections in Open-Source TypeScript

**Proposed title:** *Uncertainty-Aware IEC 60891 Correction: A GUM-Compliant TypeScript Implementation for Open-Source PV Testing*

**Target venue:** MDPI Energies (IF 3.2) or Measurement (Elsevier IF 5.6)

**Engineering anchor (surya-yantra):**
- `apps/web/lib/iec60891.ts` — Procedures 1–4 (IEC 60891:2021)
- `apps/web/lib/smmf.ts` — IEC 60904-7 spectral mismatch factor
- `apps/web/lib/iam.ts` — Martin-Ruiz IAM model (`ar = 0.17` default)
- Pending: `lib/uncertainty.ts` — GUM budget (tracked in issues #209, #176)

**Narrative thread:**  
India's NABL accreditation push (MNRE PLI scheme for high-efficiency modules)
requires every PV test lab to document expanded measurement uncertainty (k=2,
95 % confidence). Surya Yantra's open-source IEC correction engine provides a
reproducible, citable implementation. This paper would:

1. Derive GUM sensitivity coefficients for all four IEC 60891 procedures
2. Publish a complete uncertainty budget (dominant contributor by technology)
3. Validate via Monte Carlo (N=10,000) for TOPCon, HJT, IBC, and CdTe modules
4. Benchmark U(P_mpp) against proprietary systems (Halm CTM, Spire 4600SLP)

## Seed B: Real-Time PV IV Tracing via WebSocket + GanitaSutra SimuFlow Integration

**Proposed title:** *From Instrument to Simulation: A WebSocket Bridge Between a Live IV Tracer and a MATLAB-Compatible Browser Platform*

**Target venue:** Solar Energy (Elsevier IF 6.7) or IEEE Journal of Photovoltaics

**Engineering anchor (surya-yantra + GanitaSutra):**
- `apps/web/app/api/ws/route.ts` — Socket.IO IV streaming endpoint
- `apps/web/components/LiveIVChart.tsx` — real-time Recharts overlay
- GanitaSutra SimuFlow — browser-native block-diagram simulator
- Proposed: SimuFlow PV toolbox node consuming `@surya-yantra/iv-engine` (issue #184)

**Narrative thread:**  
Commercial IV tracers (Halm cIV-station, Spire 4600SLP) operate as closed
silos — instrument firmware → proprietary software → Excel export. Surya
Yantra's open architecture streams raw IV data via WebSocket to any subscriber.
GanitaSutra's SimuFlow could consume this stream as a live toolbox input,
enabling real-time single-diode model fitting and power loss analysis. This
paper would:

1. Describe the WebSocket protocol (message schema, auth, back-pressure)
2. Measure end-to-end latency: SCPI scan → Socket.IO → browser chart (target < 200 ms)
3. Demonstrate SimuFlow integration for real-time 5-parameter model fit
4. Discuss open-source reproducibility and FAIR data principles
