# Surya Yantra — Research Article Drafts

This directory holds articles in progress. Promotion path:

```
drafts/ (seed → wip → review) ──► posts/ (published)
```

## Status values

| Status | Meaning |
|--------|---------|
| `seed` | Article idea + outline, generated from sibling-repo engineering activity |
| `wip` | Body being written; not peer-reviewed |
| `review` | Peer-review checklist complete; awaiting final sign-off |
| `ready` | Approved for promotion to `posts/` |
