# Open-Source IEC 60891:2021 Implementation for Real-Time PV Module IV Curve Correction

> **Status**: Outline (Monday seed). Advance to `draft` on Wednesday (add references, figures).

## Abstract

*(~200 words — fill on Wednesday)*

Most commercial PV test management systems treat IEC 60891:2021 corrections as a black box.
This paper describes a fully open TypeScript implementation of all four IEC 60891:2021
procedures — classical linear (P1), multiplicative (P2), bilinear interpolation (P3),
and shunt-aware parametric (P4) — alongside the IEC 60904-7 Spectral Mismatch Factor (SMMF)
and the IEC 61853-2 Martin-Ruiz Incidence Angle Modifier (IAM), deployed as a Vercel web
service and Electron desktop application for the Srishti PV Lab, Jamnagar.

We report numerical agreement with published IEC reference examples, discuss the order of
operations (IAM → SMMF → 60891) and its impact on uncertainty, and demonstrate end-to-end
latency of < 50 ms for a 500-point IV curve correction on Vercel's sin1 edge region.

**Keywords**: IEC 60891:2021, spectral mismatch factor, incidence angle modifier, Martin-Ruiz,
open-source, TypeScript, PV module testing, STC correction, India, Srishti PV Lab.

## 1. Introduction

### 1.1 Motivation

- Proprietary correction software (PVSyst, Halm TestBed, Spire) is expensive and opaque.
- Indian NABL-accredited labs need auditable, version-controlled correction algorithms.
- Next.js / TypeScript stack enables both web and desktop deployment from a single codebase.

### 1.2 Scope

- IEC 60891:2021 Procedures 1–4 (full).
- IEC 60904-7:2019 SMMF with trapezoidal integration.
- IEC 61853-2:2016 Martin-Ruiz IAM with beam/diffuse/albedo POA decomposition.
- 46-test Vitest suite; all tests green.

### 1.3 Out of scope

- Calibration uncertainty propagation (future work — see §7).
- Non-IEC correction methods (NREL ENPHASE, etc.).

## 3. Implementation

### 3.1 Repository structure

`apps/web/lib/iec60891.ts`, `smmf.ts`, `iam.ts` — describe file roles.

### 3.2 Procedure 1 — classical linear

Reproduce key equations; note absolute vs %/°C unit handling.

```
I2 = I1 + Isc·(G2/G1 − 1) + α·ΔT
V2 = V1 − Rs·(I2 − I1) − κ·I2·ΔT + β·ΔT
```

Warn-header when `|ΔG/G1| > 0.2` or `|ΔT| > 10 K`.

### 3.3 Procedure 2 — multiplicative

Preferred for `|ΔG| > 200 W/m²`; avoids linear over-prediction near Voc.

### 3.4 Procedure 3 — bilinear interpolation

No coefficients needed; requires two reference measurements.

### 3.5 Procedure 4 — shunt-aware parametric

Shunt resistance `Rsh` added; falls back to P2 when not supplied.

### 3.6 SMMF — IEC 60904-7

Grid harmonisation (union of wavelength grids); trapezoidal integration;
outside-domain values treated as 0.

### 3.7 IAM — Martin-Ruiz

Fixed effective AOI: diffuse = 58°, albedo = 80° (per IEC 61853-2 Annex C).

### 3.8 Correction pipeline order

```
raw IV → IAM (correct G for AOI) → SMMF (correct Isc for spectrum)
       → IEC 60891 P1–P4 (translate G,T to STC)
```

HTTP 422 if any intermediate factor ∉ [0.5, 2.0].
